# GALAXY — общий рабочий проект

Сначала прочитать `НАЧАТЬ ЗДЕСЬ.md`, `ТЕКУЩИЕ РЕШЕНИЯ.md` и README нужного слайда. Пользовательские прямые инструкции имеют приоритет. Порядок17 слайдов и композицию сохранять, если пользователь не поручает иное.

Основной PPTX в `00 Презентация/`. Работа ведётся по разделам `01 Слайды/`; пути из текущих реестров относительные к этой папке проекта. Не обращаться к старым абсолютным путям другого компьютера. Исторические документы могут содержать такие пути, они служат происхождением, а не зависимостями.

Исходники не перезаписывать. Новые редакции сохранять с номером/датой. Зафиксировать исполнителя и слайды в `ЗАДАЧИ.md`; один человек собирает итоговый PPTX. Не считать наличие файла подтверждением его актуальности или согласования. Не публиковать материалы и не отправлять сообщения без прямого поручения пользователя.

Обновлять текущие решения и реестр после согласованных изменений. Сохранять оригинальную печать лиц пачек. Не превращать презентационные реконструкции и условные размеры в подтверждённые заводские факты.
